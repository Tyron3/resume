How I test from a diagram

  1. Inventory the diagramGive every element a stable ID so nothing is tested on assumption.
  2. Log the ambiguitiesAnything the diagram doesn’t say becomes a question, not a guess.
  3. Derive test conditionsEach condition names its technique and cites the element it covers.
  4. Specify test casesConcrete steps, data and expected results, ready to automate.
  5. Map coverageA coverage matrix that shows exactly where the gaps are.
